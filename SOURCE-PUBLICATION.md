# Source publication — 1.2

The source tree is browsable in this repository and bundled in the versioned source ZIP. The device and DSP code match the exact qualified firmware. Browser presentation, installer labels and release documentation were prepared after testing; the device binary was not rebuilt. The ZIP contains a SHA-256 manifest of its own source files. It excludes personal banks, credentials, manufacturer firmware, native build output and private work logs. Original component notices and historical technical reports are retained.

Published 1.0 and 1.1 tags and release assets are preserved. Qualification and recovery instructions for this release are in `docs/release-1.2/` and `Recovery-1.2.txt`.
