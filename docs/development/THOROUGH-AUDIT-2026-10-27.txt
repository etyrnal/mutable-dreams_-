CONCRETE FIXES
1. Short gates were processed too late when a note began inside the first DSP
   tile. At 220 BPM / 1% gate, envelope state after 64 frames was 0.71749 rather
   than 0.31998. Release is now sample-accurate inside each voice's envelope.
2. The initial correction subdivided the complete six-voice rack at every gate.
   The real FM-1 exposed this: staggered 1–6% Harmonic gates reached 102.57% of
   the callback budget and produced xruns. That candidate was rejected. Final
   code keeps four normal 64-frame tiles per 256-frame callback; only the local
   envelope changes at a gate boundary. A structural regression guards this.
3. Slow tracks incorrectly multiplied the swing offset by track speed. At 120
   BPM, speed 2 and maximum swing, a 50% gate lasted 7166 rather than 5512.5
   frames. Complete long/short pairs now cancel; odd speeds retain one offset.
4. Recording a held note for roughly sixteen minutes could overflow the integer
   duration product and record a 1% gate. It now safely saturates at 100%.
5. Browser saved data is checked for valid object IDs, complete lengths and byte
   values. Invalid IDs can no longer write to WASM address zero; valid adjacent
   banks remain readable. Bad data is reported without automatically rewriting
   localStorage. The suspected repeated-save publication bug was NOT present:
   the existing write counter is correct and now has an explicit regression.
6. Background drawing rejects off-tile points before density calculations.
   Seven reactive/still captures are byte-identical; no visual detail removed.
   Three historical tests now follow the documented 1.2 GLO page sequence and
   test knob changes independently of curated factory-preset starting values.
